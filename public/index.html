mock-json

A mock blog REST API for testing REST integrations. Static JSON payloads plus serverless endpoints for the cases static hosting can't express (status codes, content types, latency, dynamic 404s). Spec: /openapi.json. All endpoints are GET-only and return Access-Control-Allow-Origin: *.
